# first-laravel

A minimal Todo app built to learn Laravel, PHP, and SQLite.

## Goal

- Learn Laravel fundamentals / CLI
- Practice PHP in a real project
- Understand database connections and migrations

## Incredible features

- Add a todo
- Done/Undo task
- Delete a todo
- Night mode following system default
